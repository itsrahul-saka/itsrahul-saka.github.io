About

About Rahul Saka

I'm Rahul Saka (@itsrahul-saka), a BTech Computer Science & Engineering (CSE) student exploring Artificial Intelligence, Machine Learning, and practical software development.

I built this workbench so that everyday developer utilities and core CSE lab topics—from sorting algorithms and Boolean truth tables to OpenAPI inspection, JWT debugging, and leak-free ML dataset splits—can be explored right in the browser without servers, trackers, or setup friction.

  • 🎓Focus: BTech CSE fundamentals, data structures & algorithms, AI/ML foundations, and clean web tools.
  • 🔒Privacy-First Design: All 21 tools execute 100% locally in your browser. Inputs, tokens, logs, and datasets are never sent to any external server.
  • ⚙️Single-File Portability: Designed to deploy cleanly on GitHub Pages (https://itsrahul-saka.github.io/) even from an Android browser.
