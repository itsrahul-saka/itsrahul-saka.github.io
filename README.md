# Rahul Saka — Portfolio

A static, GitHub Pages-compatible portfolio built with semantic HTML, modern CSS and vanilla JavaScript.

## Run locally
Open `index.html` directly, or serve this folder with any static file server.

## Deploy
Copy the contents of this folder to the root of `itsrahul-saka.github.io` and publish from the existing GitHub Pages source. No build step, package manager, backend, API key or paid service is required.

## Interaction notes
- The hanging lamp uses a damped angular spring model with pointer capture and drag momentum.
- The lamp switch is keyboard operable.
- The cat tracks the pointer on fine-pointer devices and has reduced-motion fallbacks.
- The navigation supports Escape, outside click, focus return and a focus loop.
- Section reveals and pointer ambience respect `prefers-reduced-motion`.

## Content accuracy
Only the public portfolio repository was confirmed as a project during this redesign. No dates, additional projects, email address or LinkedIn URL were inferred. Update the project list and contact details when verified material is available.

## Dependencies
No JavaScript dependencies. Google Fonts are an optional external font request; system fallbacks are defined in CSS.
