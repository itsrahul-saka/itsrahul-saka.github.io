# Rahul — Personal Portfolio

A responsive, static personal portfolio made with HTML, CSS, and vanilla JavaScript. It can be hosted free with GitHub Pages.

## Files
- `index.html` — page content and metadata
- `style.css` — responsive dark theme and layout
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html`.
2. Find `YOUR_EMAIL@example.com` and replace it with the email address you want public.
3. Replace `YOUR_GITHUB_USERNAME` and `YOUR_LINKEDIN_USERNAME` with your real profile usernames. If you do not want to share a contact method, remove that link.
4. Review the skills and project descriptions. Keep only skills you can actually use; replace starter project cards with real projects as you complete them.
5. Optionally change the title, intro, and about text.

## Publish with GitHub Pages (free)
1. Sign in to GitHub and create a **public** repository named exactly `YOUR_GITHUB_USERNAME.github.io` (replace the placeholder with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root (not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the Pages deployment to finish. Your site will be at `https://YOUR_GITHUB_USERNAME.github.io/`.

## Notes
- GitHub Pages serves static files. This site does not need a server, database, API key, or paid hosting.
- A custom `.com` domain is optional and normally costs money.
- Since the repository is public, anything you upload to it is public. Do not put passwords, API keys, private documents, phone numbers, or a home address in the site or repository.
- Google Fonts are loaded from Google Fonts. If you want the site to work without that external font request, remove the font links in `index.html` and the `@import` at the top of `style.css`; the fallback fonts will still work.
